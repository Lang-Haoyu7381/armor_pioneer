# 旧版载具包补丁脚本（存档参考）

> 返回 [项目首页](../../README.md) · [载具包说明](../README.md)

这四个 PowerShell 脚本来自 **1.0.0 时代**，当时装甲先锋以 **zip 包**分发，补丁脚本直接改写 zip 内的文件。

| 脚本 | 作用 |
|---|---|
| `add_shells.ps1` | 给载具包添加新的弹种定义 |
| `add_suspension.ps1` | 为 vvp 的履带车加大悬挂行程（`max_droop` 0.1 → 0.32） |
| `add_snorkel.ps1` | 给 T-64 / 其它车加 OPVT 通气管部件、骨骼、动画与绑定 |
| `split_rear_armor.ps1` | 把炮塔后板拆成独立部件（T-90M 的 `additional_armor_rear`） |

## 注意

**这些脚本不适用于当前的 1.1.x 包。** 自 1.1.0 起，装甲先锋已改为**文件夹形式**，改动直接编辑 `assets/` 与 `data/` 下的文件即可，不需要整包重写。

保留它们的原因是：

- 它们记录了「载具包侧要做哪些改动」的具体形态，是 [docs/载具包改动.md](../../docs/载具包改动.md) 的实例；
- 其中 `add_snorkel.ps1` 对**尚未打补丁的包**仍然有参考价值。

再次使用前，请先确认目标包的版本与结构，并做好备份。
