# 已知的限制与未覆盖的部分

> 返回 [项目首页](../README.md) · [文档索引](README.md)

- **原版环境伤害还没有装甲结算**：火焰 / 岩浆 / 闪电仍走基础模组（阈值 50 的车会被压成
  0.1/次，阈值低的车会真的掉血）。它们不是「武器打在板上」，要接管得先决定“环境伤害该不该
  被装甲挡住”。**碰撞冲击已经接管**（见「碰撞伤害」一节），不再是后门。
- **天然地面保护是「按材料」的，不是「按谁放的」**：Minecraft 不记录方块来源，所以玩家用泥土 /
  石头垒的墙也会被保护；反过来，圆石、石砖、木板、原木、羊毛、玻璃仍能撞碎。模组地形如果没有
  被正确打上原版地形标签，需要把方块 id 填进 `natural_ground_blocks`。
- **碾压没有圈地 / 权限检查**：在别人的领地里也能推平木屋和圆石墙。这是下一步才适合接的
  claim 插件兼容，不在这一版里。
- **碰撞的范围只有装甲先锋七辆**：其余包的车仍然吃基础模组的无装甲碰撞伤害，要加就把 id
  填进 `vehicle_collisions.vehicles` / `vehicle_ramming.vehicles`。
- **VVP 里的 M1 都配了**（`m1a1` / `m1a2` / `m1a1_ukr` / `m1a2_sep`，见上文「M1 系列」），
  四辆同一个外形、三个装甲世代。**SEP 的侧面装甲资料里提到有改进，这里没有建模** ——
  四辆的侧面五面完全相同；要加说一声。
- **「坦克突击」24 辆已经全部配上**（v87），「装甲先锋」的七辆也全部配上；**VVP 64 辆里还只配了
  10 辆**。剩下那些不缺数据，缺的是装甲数值 —— 那部分只能人来定。
  `add_vehicle.ps1 list` 会**逐个包**列出来。
- **三架飞机**（见上文「飞机：蒙皮与内装甲」）：
  - **数值是量级估算**，不是逐项档案：蒙皮 1.5–3mm、座椅靠背 12–14mm、风挡 40–50mm，
    按公开描述的区间取整；没有公开资料会列出“飞行员盒”“油箱盒”的毫米数。
  - **没有起火 / 冒烟 / 操纵面损伤**：油箱和发动机命中只有伤害，打机翼只算蒙皮 + 结构。
    要加“翼梁/操纵面”就是把它们写成 `components`，机制已经在了。
  - **部件自己的 health 在这三架上是 −1**（包里没写 `max_health`），所以“伤部件”实际上只有
    载具血量；额外的后果靠 `damage_multiplier` / `crew_damage` 表达。
  - **爆炸不进击落发数**：20mm 的 20 点爆炸是直击之后由基础模组另算的，表里的发数略偏保守。
  - **螺旋桨 / 桨毂没有碰撞箱**，打上去按基础模组的伤害走，不走蒙皮模型。
  - **TACZ 爆炸弹现在保留爆炸**（和基础模组一致），但一发穿几个仍然归 TACZ 管。
- **涉水套件只有 T-64 有，而且有几处**：
  - **每辆车一个块，不会跟着"同类车"走。** 想给 T-72B3M 或 T-90M 也加，就是在那辆车的条目里
    加一行 `"fording": { "max_depth": … }`，不用改代码 —— 但也不会自动继承。
  - **一次按键瞬时展开，没有准备时间。** 真实的 OPVT 要车组准备几十分钟；这里做成瞬时的，是因为
    "按了要等"会引入"按了没反应"这一类失败模式，而这个模组在那上面吃过太多次。要做就是加一个
    字段 + 一个计时器。
  - **超限会连车一起困住**（见上文「涉水套件」的警告）：这是刻意的失败模式，不是漏掉的处理。
  - **只有 T-64 有通气管模型**。给 T-72B3M / T-90M 也做，是同样一套（各自在模型里加骨 +
    各自在控制器里加绑定 + 各自在动画文件里加一条），**不是自动继承** —— 而且每辆车的炮塔形状不同，
    管子的基座位置和长度都要重新量。
  - **通气管不是可损毁部件**：它没有碰撞箱，打不着，所以不会被打掉。
  - **防水只给车上的人**（玩家和生物都算乘员），车外面的人该淹还是淹 —— 这是"车体密封"的字面意思。
    只有**提示**是只发给玩家的（生物不读动作栏）。
- **TACZ 的子弹**（见上文「TACZ 的子弹」一节）：
  - **绝大多数枪对装甲车无效，这是刻意的。** `7.62×39` / `5.56×45` 是 10mm 和 12mm，
    而本模组每辆车的侧面都是 35mm 起 —— 打不穿就是打不穿。能威胁装甲车的只有 `.50 BMG`、
    反器材枪和 RPG。
  - **命中点靠重建射线**（`子弹 position()` 到 `position() + deltaMovement()`），不是 TACZ 手里
    那个 `TacHitResult`。这两者在 `onBulletTick` 里是精确对应的，但 TACZ 哪天改了 tick 顺序，
    症状会是"打中的部位偏移"，不会报错。
  - **`pierce` 和爆炸弹不参与**：一发穿几个还是 TACZ 管，RPG/40mm 的爆炸走它自己的爆炸。
  - **弹药合集里没有 TACZ 的弹**：合集按 `Warhead × WeaponClass` 分架，小口径要新增一档。
- **M1296 只有一发榴弹可用**（见上文「M1296」一节）：包里给这门 XM813 只定义了一门武器，
  所以没有钢针条目。加一发要改载具包（`add_shells.ps1` 的 `$rounds` 表 + 一条 `ammo_penetration`）。
- **液气悬挂有几处是刻意的，也不难改**（见上文「液气悬挂」）：
  - **低头时车头可能啃进地形。** M1296 的碰撞盒底边和轮子底边等高，所以车头一低头，车头下沿就
    跟着往下走。出厂的 `max_rise` + `max_pitch` 是**一起算过**的，两个都用满时车头仍然比静止时高；
    但只低头不升车、且地形有起伏时，视觉上可能有一点啃地。这是布局决定的，真要根治得改车体模型。
  - **轮子离地的上限在载具包里，不在配置里。** 能抬多少由弹簧的 `max_droop` 决定 —— 所以
    vvp 的六辆履带车由 `add_suspension.ps1` 从 0.1 抬到 0.32，K2 和 10 式直接改 `armor_pioneer`
    包里的车辆 JSON 到 **0.60**（±5° 俯仰 + ±4° 侧倾），M1296 保持 0.26 加了保证。想要更大的行程，
    要改的是包那侧的数，不是配置里的数。
  - **状态不存档、重登回水平位**，和涉水套件、一次性爆反一致。
  - **只有名单里那九辆能用**，而那九辆是按"现实里有液气悬挂"挑的。想给别的车加，改的是
    `ArmorConfig.hydropneumatic()` 的调用列表 + 包那侧的行程（vvp 是 `add_suspension.ps1`，
    `armor_pioneer` 是包里车辆 JSON 的 `max_droop` / `max_extension`）；但**先确认那辆车在包里真有悬挂部件**（`SuspensionCheck` 会验），
    而且**先确认现实里它有** ——
    履带车现在全都有弹簧可拉，所以按键一定会动，配置写错不会报错，只会凭空多出一个功能。
  - **降下去的行程只是几何上验过。** 升的那一侧有 `max_droop` 兜底，降的那一侧真正的限制是
    **压缩量余量**（`maxCompression` 减静止压缩量），而静止压缩量同样是初始化时按车重算的、
    工具读不到。工具验的是"车体不会撞地"（0.598 格间隙 vs 0.20 的降幅），
    **"降到最低时弹簧还在不在受力"只有进游戏才知道**。
- **T-90M 的附加装甲已经配了**（见上文「T-90M」一节）。炮塔上的 `era_3/4/5`、
  `additional_armor`、`additional_armor_top` 都按部件记了值，**车体侧裙上的 `era_1`/`era_2`
  也是**（2022 覆盖前 60%、2024 覆盖 93%）。剩下没盖到的侧面仍然走 `hull_side_era`
  那条几何带。留下的是几处**已知的近似和能力缺口**：
  - **`hull_side_era` 那条带子本身没管高度。** 它是"车体侧面、从车头往后 N% 车长"，
    **高度上完全没有表达** —— 盒子**上方**那一段裸露的侧面，只要入射角够，也会按"有裙板"算。
    （盒子盖住的地方不受影响：`part_armor` 先判，而且是精确的盒子。）
  - **`part_armor` 上没有入射角门槛。** 它是无条件的，而且排在所有判定之前；角度门槛只有
    几何版的 `hull_side_era` 有。要让"打中的是 `era_1` 这块板，且角度 ≥ 30°"同时成立，
    得给 `part_armor` 加一个角度条件 —— 这是**没有的能力**，不是没配的值。
  - **一次性爆反对谁都生效，而且不存档、不变外观。** 几条都是刻意的，也都能改：
    - **命中就消耗它。** v70 起普通弹和串联弹一样：未消耗的爆反先扣 `era_hp`，然后报废。
    - **血量比穿深高就挡下。** 480mm 破甲弹打在 600 血量的 `era_3` 上，整发被板挡下、板报废；
      第二发面对的是后面的装甲。血量不够时剩下的穿深继续撞后面（800 − 600 = 200，再撞 250）。
    - **重开世界就恢复。** 状态只存在内存里（按载具实体、弱引用），没有写进存档 —— 把装甲状态
      写盘是另一件事，而且基础模组自己的部件损毁本来也不跨存档保留。
    - **打掉之后模型上那块板还在**，只是结算时不算它了。要让外观也跟着变，得动载具包那边的
      部件，不是本模组这一侧的事。
  - **`era_hp` 写 0 或不写就是普通装甲。** v70 起没有会拼错的名字；旧文件的
    `"era": "light"|"heavy"` 在升级时按 `thickness` 转成 HP。**静默失败的方向**变成了
    "这块板忘了写血量" —— 它看起来像普通钢板，数字全都正常，所以 `adoptReactiveHp` 会从默认
    里补。`part_armor` 的键写错仍然更彻底：那个盒子一次都不会被命中，因为查找用的是部件 id
    （`VehicleScaffold` 会拦下来，见下文）。
- **T-72B3M 的装甲是初稿，而且它的 Relikt 只做了侧面那一半。** 现实里炮塔正面也挂着 Relikt，
  但**模型上没有独立的爆反部件**（`turret_part_ids` 里只有炮塔本体、高射机枪、烟幕发射器、
  车长机枪四个），所以炮塔那 480mm 是把"复合装甲＋爆反"当成一整块给的，**不是** 底甲 + 盒子。
  侧面能写是因为侧裙走的是**几何带**（按角度判定），不要求部件存在 ——
  **T-90M 的侧裙现在改成部件了，正是因为它有那几个部件**；T-72B3M 没有，所以还留在几何带上。
  要给炮塔也做爆反，需要**载具包这边给炮塔加独立的爆反部件** —— 那是改包，不是改配置。
  （T-90M 的炮塔后板就是这么做的，见「炮塔后方的装甲板（`split_rear_armor.ps1`）」——
  同一个套路可以照搬。）
- **T-90M 的炮塔后板是唯一一个"配置依赖改包"的值**。`additional_armor_rear` 只有打过补丁的包
  才有；没打过的包上这一行是死的，`VehicleScaffold` 会 FAIL，但游戏里不会报错、那块板仍按
  `additional_armor` 的 600 算。**这和通气管是同一类**（模型是包那边的事），区别是通气管没有值、
  这个有。
- **同一个工具管两个包**：命名空间是从包的 `vehicle_pack.meta.json` 读的，不是写死的，
  所以 `tank_assault:panther` 和 `vvp_ywzj:t64` 用同一条命令适配。`check` 模式会**遍历所有
  已安装的包**各验一遍 —— 只验一个包会给你一个"通过"，而那个通过只覆盖了半个配置文件。
- **烟雾发射器的可见模型现在就是用户标记的 `smoke` 骨**（见「烟雾弹（按 H，基础模组的
  发射方式）」）：结构模型里每根管一个对应的轴对齐盒和一个显式 bolt；K2 在 2026-11-11 新增
  前部一簇后是 **21 根**。**K2 的旧附件里另有 122 个恢复的显示履带方块和 13 个被删的
  `hull_details2` 方块，那不是烟雾标记**，所以链接模型履带保持原样。
- **结构盒是管子的世界 AABB，不是旋转盒。** 一根斜置的管子用轴对齐盒包住会略大，而且
  五辆车的炮塔盒本身是一整块粗盒，盒子都在炮塔盒内部 —— 从外面打过来可能先命中炮塔盒，
  烟雾部件的盒子主要用于“打中发射器算炮塔”和给 `part_armor`/乘员舱室一个部件 id。
  如果以后要精确到每根管的旋转碰撞盒，得把结构盒换成带 pivot/rotation 的方块（基础模组
  会为它们生成合成子骨），这超出这次烟雾标记的范围。
- **每根管的方向取的是管子长轴朝上/朝前的一端**，不是炮塔正前方；VT-5 正前上方，VT-4 /
  K2 / 天马-20 左右略向外，10 式向外 6°。要改成统一朝前，改的是车辆 JSON 里各 bolt 的
  `x_rot`/`y_rot`，不用动模型。
- **吨马力只影响加速和转向，不改变最高速。** 基础模组的 `getSuspensionPowerScale` 被
  一个 mixin 乘上发动机倍率，而基础求解器把这个 `powerScale` 只用在
  `forward/backwardAcceleration`、`maxTurn` 和 `turnAcceleration` 上；最高速是另一个夹子，
  刹车也不乘它。所以 VT-5 比 VT-4 更快到达自己的 70 km/h，但两辆车的 70 km/h 不变。
  VT-5 的公开 hp/t 按 33 t 基本型引用，而包的 `mass` 是 42.9 t —— HUD 显示公开值，
  两个数的差是包的质量，不是错误。
- **烟雾弹一次只放一排。** 每组是一排**发射管**（按深度），不是左右两侧；每排四根。
  组数随管数（12 管三排、10 式两排）。想一次齐射全部管，目前得按 N 次 H，没有"全放"键。
