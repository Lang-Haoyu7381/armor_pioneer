`design/` 目录存放伤害模型的曲线图与拟合脚本：

| 文件 | 内容 |
|---|---|
| `kinetic_penetration.md` | 动能穿深的推导笔记 |

| `he_model_plots.py` / `.png` | 高爆伤害模型的曲线 |
| `crew_chemical_plots.py` / `.png` | 破甲射流对乘员伤害的曲线 |
