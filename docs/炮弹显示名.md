# 炮弹的显示名（真实型号）

> 返回 [项目首页](../README.md) · [文档索引](README.md)

载具包里的炮弹**显示名**改成了真实型号，格式为 `型号-口径 弹种`。**武器 id 一个都没动** ——
已有存档、已有配置、其它载具对炮弹的引用全都不受影响，变的只有选择器和弹药合集里读到的那行字。

| 武器 id（不变） | 原名 | 现名 |
|---|---|---|
| `2a46m1_125mm_apfsds` | 2A46M-1 125mm (APFSDS) | **3BM42-125mm APFSDS** |
| `2a46m1_125mm_heat` | 2A46M-1 125mm (HEAT) | **3BK18M-125mm HEAT** |
| `2a46m1_125mm_he` | 2A46M-1 125mm (HE) | **3OF26-125mm HE** |
| `2a46m1_125mm_he_vt` | 2A46M-1 125mm (HE-VT) | **3OF26-VT-125mm HE-VT** |
| `m256_120mm_apfsds` | M256 120mm (APFSDS) | **M829-120mm APFSDS** |
| `m256_120mm_heat` | M256 120mm (HEAT-FS) | **M830-120mm HEAT** |
| `m256_120mm_heat_mp` | M256 120mm (MP-HEAT) | **M830A1-120mm MPAT** |
| `2a46m5_125mm_t90m_apfsds` | 2A46M-5 125mm (APFSDS) (T-90M) | **3BM60-125mm APFSDS** |
| `2a46m5_125mm_apfsds` | 2A46M-5 125mm (APFSDS) | **3BM60-125mm APFSDS** |
| `ztm1_30mm` | ZTM-1 30mm | **ZTM-1-2**（弹链名，见下） |
| `ztm1_30mm_apfsds` | ZTM-1 30mm (APFSDS) | **ZTM-1-1**（弹链名） |
| `xm813_30mm` | XM813 30mm | **XM813-2**（弹链名） |
| `xm813_30mm_apfsds` | （本模组新加的） | **XM813-1**（弹链名） |
| `m256_120mm_he`（脚本里，默认关闭） | M256 120mm (HE) | **M908-120mm HE** |

- 3BM42「芒果」是 2A46M-1 的标准钢针，3BK18M 是它的破甲弹，3OF26 是它的榴弹；
  M829 是 M256 的标准钢针，M830 是它的多用途破甲弹（HEAT-MP-T），**M830A1 就是"多用途"那一发**
  —— 正是那颗可切引信的弹；
- **四条 30mm 的名字是「弹」不是「弹链」**：3UBR8 / 3UOF8 是 30×165 的钢针和榴弹，MK258 是
  30×173 的钢针 —— 一条链装两发弹，按 F 时动作栏报的就是**当前这一发**的名字，所以名字必须是
  弹的型号。弹链自己**没有名字**（见「双路供弹」一节）。
  **3BM60「Svinets-2」是 2A46M-5 的钢针**，也是 T-90M 的默认装填（包里的原名叫的是炮不是弹，
  和当年 T-64 那门一样）。
- **改名是按文件做的，所以对所有用这门弹的车一起生效**：`m256_120mm_apfsds` 在四个 Abrams
  型号上都有，`ztm1_30mm` 在 BTR-3 和 BTR-4 上都有，一次改完全都跟着变。这是想要的效果 ——
  同一门炮的同一种弹不该有两套名字。
- **3BM60 那条要写两遍，因为载具包把它分成了两个武器 id**（T-90M 的和 T-72B3M 的），
  而它们是**同一门炮的同一发弹**。只改一个的话，弹药合集里会并排出现两行 —— 一行写着 3BM60，
  一行写着"2A46M-5 125mm (APFSDS)"，读的人自然会以为这是两种弹。
- **机枪没改**：它们本来就是按枪命名的（PKT / NSVT / M240 / M2HB / KT-7.62），而且"7.62mm
  子弹"的型号（7N1、M80…）和你给的 `型号-口径 弹种` 格式对不太上。要一起改说一声。
- **`m256_120mm_he` 那一条是推的**：美军 120mm 没有在编的普通榴弹，最近的实弹是 M908（破障弹）。
  这条默认是关掉的，改与不改都不影响游戏。

> 改名写在 `add_shells.ps1` 里，分两类：**脚本自己写的弹**名字由生成器直接带上（`Name` 字段，
> 全脚本只有一份）；**载具包原本就有的弹**由 `$renames` 表就地改 `"name"` 字段。
> 两类都会在脚本末尾**读回来核对** —— 名字静静保持旧样和"改成功了"在外表上一模一样。
