# 验证是否生效

> 返回 [项目首页](../README.md) · [文档索引](README.md)

启动时控制台应出现：

```
[VehicleArmor/]: [Vehicle Armor] 18 vehicle profile(s), 55 ammunition entry(ies), 2 with a switchable fuze, multiplier x50.0 front / x5.0 side-rear, angle normalization off
```

**「1 with a switchable fuze」是这几项里唯一一个会暴露"武器 id 对不上"的数字。** 配置里写的 id
和载具包里的 id 一旦不一致，`ammoFor()` 就返回 null，装甲计算整条绕过、**一行错误都不打**，
只剩这颗弹谁也点不着火。变成 0 就说明对不上了。

条目数从 11 涨到 **14** 是 v19 → v20 带来的 BTR-3 三发（30mm 钢针、30mm 高爆、KT-7.62）。
数不对就说明配置没升级成功。载具数也从 2 变成 **3**。

用 2A46M-1 125mm APFSDS 打一发 T-64，每次结算都会打一行 INFO 日志并标出命中部位：

```
[VehicleArmor/]: [Vehicle Armor] vvp_ywzj:t64 hit on track front: plate 200.0mm, penetration 457.0mm, residual 257.0mm, damage 385.5
```

部位标签：`turret` / `turret gun mount` / `track front` / `track rear` / `hull` /
`hull upper front` / `hull lower front` / `hull machine-gun port` / `road wheels` /
`hull side (reactive)`。

被顶掉爆炸伤害时会再打一行，带上原本会扣的血量 —— 看到它就知道爆炸确实被拦下了：

```
[VehicleArmor/]: [Vehicle Armor] vvp_ywzj:t64 blast of 1312.5 damage dropped by vvp_ywzj:2a46m1_125mm_heat; this round carries its own
```

涉水套件每次展开/收起也打一行，带上它算出来的判决和水深 —— **这一行是"注入到底有没有生效"唯一的
运行期凭据**（脱机工具跑不了 mixin）：

```
[VehicleArmor/]: [Vehicle Armor] Steve fording kit deployed on vvp_ywzj:t64: WADING (depth 3.4 of 5.0)
```

判决是 `NO_KIT` / `RETRACTED` / `DRY` / `WADING` / `TOO_DEEP` / `NOT_WATER` 之一。
按 K 之后**动作栏什么都没有**，就是这个包没送到服务端（客户端会在 1.5 秒后提示"服务端未安装"）。

涉水套件的冒烟清单（因为它的效果全在水里，光看日志看不出来）：

| 试什么 | 期望 |
|---|---|
| T-64 按 K，开出日志 | 动作栏报"已展开"，日志一行 `WADING` 或 `DRY` 且末尾 `snorkel part: yes` |
| 同一时刻看炮塔顶 | **管子在一秒多里升起来**，停在炮塔上方约 2 格 |
| 转动炮塔 | 管子跟着炮塔一起转，不脱离、不打滑 |
| 顺便看一眼炮塔射击、履带滚动 | 和以前**一模一样**（改控制器最大的风险就在这里） |
| 再按一次 K | 动作栏报"已收起"，管子缩回去，下水立刻恢复成熄火 |
| 收起状态贴着车走一圈 | 看不到管子从车底或炮塔缝里露出来 |
| 展开后开进河里 | 不熄火、能沿着河床开 |
| 潜到 4 格深左右 | 收到一次"再深就要进水"的提醒 |
| 开进 6 格以上 | 收到"发动机进水熄火"，车停住 |
| 坐在车里潜到河底 | 不掉血，HUD 上多一个水下呼吸图标 |
| 存档后重进 | 管子**是收起的**（状态不存档，每 tick 会把部件对齐回布尔） |
| **BMP / BTR 不按 K 直接下水** | 照旧能过水（确认基础模组那批两栖车没被改坏） |
| 开进岩浆 | 照旧熄火 |
| 服务器没装本模组时按 K | 动作栏提示"服务端未安装" |
| 载具包**没打**补丁时按 K | 套件照样生效，回复多一句"模型里没有通气管部件"，日志 `snorkel part: NO` |
