# 键位

> 返回 [项目首页](../README.md) · [文档索引](README.md)

本模组自己的键位全部注册成标准 `KeyMapping`，在 **选项 → 控制 → 按键设置 → 装甲附属** 里改绑，
和原版 / 基础模组的键位一起保存。默认值：

| 动作 | 默认键 | 说明 |
|---|---|---|
| 装填选择 / 俯仰修饰键 | **左 Alt** | 轻按（不配合其它键）在松手时打开装填选择；按住时配合基础模组的**前进 / 后退**调车体俯仰 |
| 车体升高 / 扫描仪上页 | **↑** | 扫描仪拿在手上时，↑ 翻页而不是抬车体 |
| 车体降低 / 扫描仪下页 | **↓** | 同上 |
| 悬挂左倾 / 引信切换 | **←** | K2 / 10 式的驾驶员是侧倾；其它车 / 座位是引信切换 |
| 悬挂右倾 / 引信延时 | **→** | 同上 |
| 涉水套件 | **K** | 只有驾驶员能操作 |
| 舱盖开合 | **P** | 开 / 关离自己座位最近的舱盖 |
| 混动模式 | **G** | 只有 ZTZ-100；其它车按 G 仍是基础模组的起落架键 |
| 夜视仪 | **5** | 装甲先锋炮手镜 |
| 舱盖潜望镜 | **Y** | 车长席 |

- **方向键和 G 与基础模组的键位共享**：本模组从不取消事件、也不消费按键，所以直升机仍然用
  方向键做功能控制、飞机仍然用 G 收起落架；服务端会判断这一下在不在本模组的车辆上生效。
  按键设置里出现红色冲突提示是正常的 —— 它想让你知道这两个键是共用的。
- **俯仰不是单独的键**：修饰键是「装填选择」，方向键是基础模组的**前进 / 后退**。改这三个
  键中的任何一个，复合键都会跟着变。
- 夜视和潜望镜原本就在按键设置里，这次只是把分类从基础模组的「载具」移到了「装甲附属」；
  已保存的改绑不受影响（绑定按 `key.ywzj_vehicle_armor.*` 的名字保存）。
- **验证**：新增 `tools/KeyBindCheck.java`，确认每个键都有 `KeyMapping`、都在 `ClientSetup`
  里注册、都被对应的处理器读取、默认值与上表一致、两个语言文件都有名字，并确认两个世界
  处理器里不再残留 `key.keyboard.*` 字面量（GUI 自己的翻页键除外）。
